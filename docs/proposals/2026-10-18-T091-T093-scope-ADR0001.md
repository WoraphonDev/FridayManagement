# Proposal: align T-091 and T-093 scope with ADR-0001 (PostgreSQL / Linux + Docker)

**Status:** DRAFT. Not applied; needs owner approval. · **Date:** 2026-10-18 · **Declared effort:** Medium (actual NOT_VERIFIED, prepared by Claude Opus 5.5)

## Why

ADR-0001 (owner decision 2026-10-11, reaffirmed 2026-10-17) retires SQL Server 2022/Windows from acceptance and release scope. The Task Register header already says SQL2022/Windows evidence is superseded. However, two tasks still name SQL Server/Windows as acceptance steps:

- **T-091:** title, checklist, and manifest `verification` say "SQL Server 2022 native และ Windows".
- **T-093:** ticket asks for a ZAP scan on "staging Windows + SQL Server 2022", and its "Not Do" line refers to SQL Server criteria.

As written, neither task can be closed under the current production target. The changes below are wording and scope only. Acceptance tests (AT-31–AT-40), dependencies, effort and business rules stay the same.
