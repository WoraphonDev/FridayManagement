## Technical contract proposal — รอ human specification approval

Current locked wire: API prose/OpenAPI/generator **1.15.0**, **89 routes / 120 schemas**. `GET /api/directory` operationId `get_api_directory`, `x-permission=admin_or_any_active_lead`, `x-owner-tasks=[T-021,T-024,T-069]`, `x-idempotency=none`, 200 `DirectoryPersonPage`. ### Query และลำดับ errors ที่เสนอ

| Field / input | Exact proposal (ไม่ใช่คำตอบ technical ที่ Zo เลือกแล้ว) |
|---|---|
| `project` omitted | Legacy Admin/any existing access Lead authorization + response/search/paging เดิมทุกประการ; ไม่ตีความ missing ว่า current project หรือ global P-03 grant |
| `project` present | Optional scalar `Id`: canonical decimal integer **1..2147483647**; เพียง presence เลือก scoped mode หลัง validation ไม่ใช้ truthiness. `project=`, `0`, `-1`, `+1` (รวม URL-decoded space), `01`, `1.0`, `1e2`, `null`, whitespace, overflow, bracket/array/comma syntax → **400 INVALID_QUERY**; ไม่มี invalid→legacy fallback |
| Known scalars | `project`, `q`, `page`, `pageSize` ส่งซ้ำ **แม้ค่าเท่ากัน** → 400 INVALID_QUERY เช่น `project=1&project=1`, `q=&q=`, repeated pagination. Unknown fields รวม `username`, `team`, `includeInactive`, `project[]`, `q[]`, `sort` → 400; ไม่ strip |
| Pagination | page default1, range1..2147483647; pageSize default50, range1..100. Canonical integer decoding เหมือน project; empty/zero/noninteger/out-of-range/duplicate → 400. Order `id ASC` stable tie-breaker; page เกินท้ายคืน `items:[]` + scoped matched eligible total ไม่เปลี่ยนหน้าเอง |
| `q` | Optional string, **0..100 Unicode scalars และ ≤100 UTF16 code units** ตาม text(100). Omitted/empty string = ทุก eligible name; whitespace-only เป็น **literal search ไม่ trim** ตาม legacy behavior. ชื่อเท่านั้น ไม่ค้น username/email/job title/team. Thai/emoji ส่งด้วย URL encoding; ไม่เพิ่ม casefold/normalization contract ใหม่. `%`, `_`, `[`, backslash เป็น literal escaped LIKE search; parameterized SQL; เกิน UTF16/scalar limit → 400 |

**รักษา locked precedence ไม่สลับ auth-first:** API §6 กำหนด ingress syntax ก่อน session/resource/rights; actual `middleware.process` เรียก `queryFor` ก่อน session/password และ preflight authorization. ดังนั้น malformed/unknown/repeated query → **400 INVALID_QUERY แม้ session หาย/expired/inactive หรือ must-change-password**; path matching/ingress failures คงลำดับเดิม. สำหรับ **valid query**: missing/expired/revoked/inactive session → **401 UNAUTHENTICATED**; authenticated forced-password → **403 PASSWORD_CHANGE_REQUIRED** ก่อน project lookup; แล้ว project absent/invisible → **404 NOT_FOUND**, visible project แต่ไม่ใช่ authorized scoped actor → **403 FORBIDDEN**. Editor/Viewer+P-03 หรือ manager ไม่มี P-03 ที่ยังเห็น project =403; unrelated actor มองไม่เห็น =404; unrelated-team Lead ที่เห็น projectในฐานะ Viewer =403 ไม่ bypass ด้วย legacy Lead grant. ไม่คืน names/total/currentVersion/hidden project detail ใน errors

No new error codes/envelope/order. GET ไม่มี expected membership version, Origin/CSRF หรือ idempotency key เพิ่ม; no-store/X-Request-Id และ existing busy/unavailable errors เดิม. PUT/DELETE คง current actor auth/resource/operation-rights-before-version precedence: lost visibility404/actor operation denial403 มาก่อน stale409 และ `currentVersion` ส่งเฉพาะ resource ที่ยังเข้าถึงได้; ไม่ใช้ discovery snapshot เป็น authorization/version token. Source service ตรวจ target active/old explicit manager หลัง requireVersion อยู่แล้ว จึงไม่เสนอ reorder หรืออ้างว่า target error ทุกชนิดต้องชนะ409
